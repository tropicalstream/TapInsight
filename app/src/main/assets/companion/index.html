+
Phone GPS Bridge (Optional Module)

Off by default. When enabled from a phone, TapInsight can use this phone's GPS as a high-accuracy location source for maps and nearby-place queries. If left off, the glasses keep using the existing location pipeline unchanged.

Step 1: turn this module on. Step 2: tap Use This Phone's GPS to request permission and send the first fix. This only affects maps/location flows while the module is enabled and receiving fresh phone fixes.
