## TapInsight OC3

TapInsight OC3 packages the latest publishable alpha from the current working tree.

### What Changed

- Closed captions now display more reliably by default in YouTube video mode.
- Gemini routing is less likely to auto-play YouTube when the user is asking an informational question.
- Saying `status` now triggers the intended OpenClaw heartbeat plus current/next Google Calendar briefing.

### Included Assets

- `tapinsight-oc3.apk`
- `TapInsight-tapinsight-oc3-source.tar.gz`

### Notes

- This release is built from a scrubbed clean export, not from the active working directory.
- The GitHub repo landing page and the GitHub Pages site have both been updated for OC3.
